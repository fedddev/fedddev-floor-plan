# Facility data

The seven facilities (DC01–DC07) are fictional. Their floor plans and layouts are generated by
`scripts/generate-facilities.mjs`. The generator uses a fixed random seed, so each run gives the
same output.

From the project root:

```sh
node scripts/generate-facilities.mjs              # all facilities
node scripts/generate-facilities.mjs DC03 DC05    # just these
```

For each facility it writes:

| File | Contents |
|---|---|
| `public/floors/{NAME}.png` | Floor-plan mask: R = walls, G = equipment and site lines (recolored by `useFloor.ts`) |
| `src/data/{NAME}/facilitySpace.json` | Facility size in metres |
| `src/data/{NAME}/sectorSpaces.json` | Halls and their bounds |
| `src/data/{NAME}/podSpaces.json` | Containment pods (origin = ROW01 start) |
| `src/data/{NAME}/rowSpaces.json` | Two cabinet rows per pod |
| `src/data/{NAME}/cabinetSpaces.json` | Cabinets; the app lays them out along their row |

A full run also writes `src/data/facilities.json` and `src/data/cabinetTypes.json`. That catalog is
generic: RPP types 10/11/12 are the A/B/C power feeds colored in `AllCabinets.vue`.

Coordinates are metres from the floor plan's top-left corner: x to the right, z down.
To change a building, hall arrangement or yard, edit `FACILITIES` in the generator and run it again.
